# Retired narration (9.4.40)

The owner removed all read-aloud from Waldpost on 23 November 2026: the recorded Piper explanations and letters were unintelligible and device speech was unreliable. The speaker buttons in Rätsel, the Rätsel-Prüfung and handwriting, the speech engine `FK.forestVoice` and the ducking of forest and game sounds during speech are gone.

This folder keeps the last runtime copies for reference only. Nothing loads them.

- `speech.js`: former `js/core/speech.js` (recorded clip first, Web Speech fallback).
- `narration/`: former `assets/audio/narration/` with `clips.js` (transcript → file) and the MP3 recordings. Rätsel explanations: Piper MLS medium, speaker 2037 (Multilingual LibriSpeech, CC BY 4.0). Letters: Piper Kerstin low (Kerstin dataset, CC0).
